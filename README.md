An SBVR Structured Englished to SBVR Logical Formulation parser.

## Typings

The output types (eg `AbstractSqlModel`) come from `@balena/abstract-sql-compiler`, which is an optional peer dependency because it is only needed for the types. Install it alongside this package to get them, otherwise they resolve to `any` when `skipLibCheck` is enabled, or fail to resolve when it is not.
